## 什么是差分？

### 差分的定义

差分是前缀和的**逆运算**。

| 算法 | 作用 | 方向 |
|------|------|------|
| 前缀和 | 将数组 a[] 转换为 prefix[]，支持 O(1) 区间查询 | 累计 |
| 差分 | 将"区间操作"转换为"点操作"，支持 O(1) 批量修改 | 拆分 |

### 核心思想

```
前缀和：    a[] ──────────→ prefix[]（累计）
差分：      a[] ←────────── diff[]（逆运算）

差分的核心：
    如果要对区间 [l, r] 加上值 v
    朴素做法：遍历 O(r-l+1)
    差分做法：diff[] 上 O(1) 操作
```

### 直观理解

```
差分数组 diff[i] = a[i] - a[i-1]

原数组:  [  1,   3,   6,   4,   8  ]
差分:    [  1,   2,   3,  -2,   4  ]
          a[1]  3-1  6-3  4-6  8-4

通过前缀和还原：
    位置1: 1
    位置2: 1 + 2 = 3
    位置3: 3 + 3 = 6
    位置4: 6 + (-2) = 4
    位置5: 4 + 4 = 8
```

## 一维差分

### 问题引入

**问题**：给定数组 `a[]`，有 `q` 次操作，每次将区间 `[l, r]` 的所有元素加上值 `v`。最后输出操作完成后的数组。

**朴素做法**：每次遍历区间，时间复杂度 O(n×q)。

**差分做法**：O(n+q)。

### 差分数组的定义

对于数组 `a[]`，构造差分数组 `diff[]`：

```
原数组:  a[1]  a[2]  a[3]  a[4]  a[5]  ...
差分:    diff[1] diff[2] diff[3] diff[4] diff[5] ...

其中:
diff[1] = a[1]
diff[2] = a[2] - a[1]
diff[3] = a[3] - a[2]
diff[4] = a[4] - a[3]
...
diff[i] = a[i] - a[i-1]  (i >= 2)
```

### 核心操作：对区间 [l, r] 加上 v

```
差分的魔力：对区间的操作变成对点的操作！

对区间 [l, r] 加上 v，等价于：
    diff[l] += v      // 从 l 开始，增加 v
    diff[r+1] -= v     // 从 r+1 开始，减少 v（结束标记）

为什么？
    diff[l] += v 后，通过前缀和还原时，位置 l 之后的所有元素都会 +v
    diff[r+1] -= v 后，从 r+1 之后就不再增加了
```

### 图示理解

```
原始数组 a:    [0, 0, 0, 0, 0, 0]
差分数组 diff:  [0, 0, 0, 0, 0, 0]

操作1: 对区间 [2, 4] 加上 5
diff[2] += 5  →  [0, 5, 0, 0, 0, 0]
diff[5] -= 5  →  [0, 5, 0, 0, -5, 0]

通过前缀和还原:
位置1: 0
位置2: 0 + 5 = 5
位置3: 5 + 0 = 5
位置4: 5 + 0 = 5
位置5: 5 + (-5) = 0  ← 结束
位置6: 0 + 0 = 0

还原后: [0, 5, 5, 5, 0, 0] ✓

操作2: 再对区间 [3, 5] 加上 3
diff[3] += 3  →  [0, 5, 3, 0, -5, 0]
diff[6] -= 3  →  [0, 5, 3, 0, -5, -3]

通过前缀和还原:
位置1: 0
位置2: 0 + 5 = 5
位置3: 5 + 3 = 8
位置4: 8 + 0 = 8
位置5: 8 + (-5) = 3
位置6: 3 + (-3) = 0

还原后: [0, 5, 8, 8, 3, 0]
```

### 代码实现

```cpp
// 方法一：先构造差分数组，再操作
// 1. 构造差分数组
diff[1] = a[1];
for (int i = 2; i <= n; ++i) {
    diff[i] = a[i] - a[i-1];
}

// 2. 进行 q 次区间操作
for (int i = 0; i < q; ++i) {
    int l, r, v;
    cin >> l >> r >> v;
    diff[l] += v;
    diff[r+1] -= v;  // 注意：如果 r == n，可以省略
}

// 3. 通过前缀和还原
for (int i = 1; i <= n; ++i) {
    if (i == 1) {
        a[i] = diff[i];
    } else {
        a[i] = a[i-1] + diff[i];
    }
}
```

### 模板（推荐）

```cpp
// 方法二：不需要预先构造差分数组，直接使用（更简洁）
int n, q;
cin >> n >> q;

int diff[1005] = {0};

while (q--) {
    int l, r, v;
    cin >> l >> r >> v;
    diff[l] += v;
    diff[r+1] -= v;
}

for (int i = 1; i <= n; ++i) {
    diff[i] += diff[i-1];  // 前缀和操作：原地修改
    cout << diff[i] << " ";
}
```

## 二维差分

### 问题引入

**问题**：给定 `n×m` 的矩阵，有 `q` 次操作，每次将子矩阵 `[x1,y1] 到 [x2,y2]` 的所有元素加上值 `v`。最后输出操作完成后的矩阵。

**朴素做法**：每次遍历子矩阵，时间复杂度 O(n×m×q)。

**差分做法**：O(n×m+q)。

### 二维差分的核心操作

对子矩阵 `[x1,y1] 到 [x2,y2]` 加上 `v`：

```
diff[x1][y1]     += v      // 左上角
diff[x1][y2+1]   -= v      // 右上角
diff[x2+1][y1]   -= v      // 左下角
diff[x2+1][y2+1] += v      // 右下角
```

![image-20260325142242993](/home/michael/.config/Typora/typora-user-images/image-20260325142242993.png)

### 为什么是这四个点？

类比一维：区间 `[l, r]` 加 v → `diff[l] += v, diff[r+1] -= v`

二维扩展：子矩阵 `[x1,y1] 到 [x2,y2]` 加 v → 四个角的操作

```
+-------------------------+
|                         |
|                         |
+ (x1,y1)                 |
|  |////|████████████████|
|  |////|████████████████|
|  +----+ (x2,y2)---------+
|       |                  |
|       |                  |
+-------------------------+

对角线原则：
    四个角：右上、左下、右下、左上
    操作规律：
        左上角:     +v
        右上角:     -v
        左下角:     -v
        右下角:     +v
```

### 图示分解四个操作

```
原矩阵加 v 后的差分变化：

第一步：diff[x1][y1] += v
+-------------------------+
|///////|                 |
|///////|                 |
+///////+                 |
|       |                 |
|       |                 |
+-------------------------+
   蓝色区域都会 +v

第二步：diff[x1][y2+1] -= v
+-------------------------+
|///////|-------vvvvv------|
|///////|-------vvvvv------|
+///////+-------+vvvvv-----+
|       |///////|           |
|       |///////|           |
+-------------------------+
   右边的灰色区域 -v（抵消蓝色）

第三步：diff[x2+1][y1] -= v
+-------------------------+
|///////|-------vvvvv------|
|///////|-------vvvvv------|
+///////+-------+vvvvv-----+
|///////|-------|           |
|///////|-------|           |
+-------------------------+
   下边的灰色区域 -v（抵消蓝色）

第四步：diff[x2+1][y2+1] += v
+-------------------------+
|///////|-------vvvvv------|
|///////|-------vvvvv------|
+///////+-------+vvvvv-----+
|///////|-------|vvvvv-----|
|///////|-------|vvvvv-----|
+-------------------------+
   右下角 +v（补回右下角）
```

### 代码实现

```cpp
// 差分数组（初始化为0）
int diff[105][105] = {0};

// 对子矩阵 [x1,y1] 到 [x2,y2] 加上 v
void add(int x1, int y1, int x2, int y2, int v) {
    diff[x1][y1] += v;
    diff[x1][y2+1] -= v;
    diff[x2+1][y1] -= v;
    diff[x2+1][y2+1] += v;
}

// 进行 q 次操作
for (int i = 0; i < q; ++i) {
    int x1, y1, x2, y2, v;
    cin >> x1 >> y1 >> x2 >> y2 >> v;
    add(x1, y1, x2, y2, v);
}

// 通过二维前缀和还原（差分的逆操作 = 前缀和）
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1];
    }
}

// 此时 diff[][] 就是操作后的原数组
```

### 模板（推荐）

```cpp
int n, m, q;
cin >> n >> m >> q;

int diff[105][105] = {0};

// 接收 q 次操作
while (q--) {
    int x1, y1, x2, y2, v;
    cin >> x1 >> y1 >> x2 >> y2 >> v;
    diff[x1][y1] += v;
    diff[x1][y2+1] -= v;
    diff[x2+1][y1] -= v;
    diff[x2+1][y2+1] += v;
}

// 还原：二维前缀和
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1];
        cout << diff[i][j] << " ";
    }
    cout << endl;
}
```

## 前缀和 vs 差分

### 关系图

```
前缀和 (累计):
    原数组 a[] ──────→ prefix[]

差分 (逆运算):
    原数组 a[] ←────── diff[]

差分的逆运算 = 前缀和！
```

### 功能对比

| 算法 | 输入 | 输出 | 核心操作 |
|------|------|------|----------|
| 前缀和 | 数组 a[] | prefix[] | prefix[i] = prefix[i-1] + a[i] |
| 差分 | 操作序列 | 最终数组 | diff[l] += v, diff[r+1] -= v |

### 时间复杂度对比

| 问题 | 朴素做法 | 前缀和/差分做法 |
|------|----------|----------------|
| Q次区间和查询 | O(n×Q) | O(n+Q) |
| Q次区间修改 | O(n×Q) | O(n+Q) |

### 选择指南

```
什么时候用前缀和？
    - 已知数组，需要多次查询区间和
    → 前缀和预处理 + O(1) 查询

什么时候用差分？
    - 需要多次对区间进行修改，最后才输出结果
    → 差分数组 O(1) 修改 + 最后前缀和还原
```

### 公式对比

```
┌─────────────────────────────────────────────────────────────┐
│                        一维版本                              │
├─────────────────────────────────────────────────────────────┤
│  前缀和构建:  prefix[i] = prefix[i-1] + a[i]                │
│  前缀和查询:  prefix[r] - prefix[l-1]                      │
│  差分操作:    diff[l] += v, diff[r+1] -= v                 │
│  差分还原:    前缀和累加                                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                        二维版本                              │
├─────────────────────────────────────────────────────────────┤
│  前缀和构建:  sum[i][j] = sum[i-1][j] + sum[i][j-1]        │
│                             - sum[i-1][j-1] + a[i][j]      │
│  前缀和查询:  sum[x2][y2] - sum[x1-1][y2]                  │
│                           - sum[x2][y1-1] + sum[x1-1][y1-1]│
│  差分操作:    四个角: 左上+, 右上-, 左下-, 右下+            │
│  差分还原:    二维前缀和                                     │
└─────────────────────────────────────────────────────────────┘
```

### 最终记忆口诀

```
前缀和与差分，两兄弟不分家。
前缀和来累计，差分来拆分。

一维差分：
    [l, r] += v → diff[l] += v, diff[r+1] -= v

二维差分：
    [x1,y1,x2,y2] += v
    → 左上 +v, 右上 -v, 左下 -v, 右下 +v

还原方法：
    差分的逆 = 前缀和
    一维：前缀和累加
    二维：二维前缀和
```

## 经典应用

### 一维差分应用

1. **区间加法模板题**：对 `[l, r]` 区间加值
2. **航班预订问题**：n个城市，Q次预订，输出每个城市最终预订数
3. **钉钉子问题**：在 `[l, r]` 区间敲打，最后哪些位置被敲了奇数次
4. **差分前缀**：配合其他算法（如单调栈）使用

### 二维差分应用

1. **子矩阵加法**：对子矩阵所有元素加值
2. **图像处理**：对矩形区域进行亮度调整
3. **地理标记**：在地图上标记矩形区域
4. **建筑施工**：对矩形区域进行施工操作

### 综合应用：前缀和 + 差分

```
问题：Q次操作，每次将 [l, r] 加上 v
      同时有 M 次查询，每次问 [x, y] 位置的值

解法：差分处理所有操作
      前缀和处理所有查询
      时间复杂度 O(n + Q + M)
```
