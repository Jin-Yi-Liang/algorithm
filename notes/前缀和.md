## 一维前缀和

### 问题引入

给定一个数组 `arr[]`，有 `q` 次查询，每次查询求区间 `[l, r]`（包括两端）的元素和。

**朴素做法**：每次遍历区间，时间复杂度 O(n)，q 次查询总复杂度 O(n×q)。

**前缀和做法**：预处理 O(n)，每次查询 O(1)，总复杂度 O(n+q)。

### 核心思想

前缀和 `prefix[i]` 表示数组前 `i` 个元素的和（从索引 1 开始）：

```
原数组:   arr[1]  arr[2]  arr[3]  arr[4]  arr[5]
            ↓       ↓       ↓       ↓       ↓
前缀和:  prefix[1] prefix[2] prefix[3] prefix[4] prefix[5]

其中:
prefix[1] = arr[1]
prefix[2] = arr[1] + arr[2]
prefix[3] = arr[1] + arr[2] + arr[3]
...
prefix[i] = arr[1] + arr[2] + ... + arr[i]
```

### 公式

**构建前缀和**：
```
prefix[i] = prefix[i-1] + arr[i]
```

**查询区间和** [l, r]：
```
区间和 = prefix[r] - prefix[l-1]
```

### 直观理解

```
数组:    [a,  b,  c,  d,  e]
前缀和:  [a, a+b, a+b+c, a+b+c+d, a+b+c+d+e]

求区间 [3, 5] 的和 = c + d + e

= (a+b+c+d+e) - (a+b)
= prefix[5]   - prefix[2]
= prefix[r]   - prefix[l-1]
```

### 代码实现

```cpp
// 构建前缀和（1-indexed）
for (int i = 1; i <= n; ++i) {
    prefix[i] = prefix[i-1] + arr[i];
}

// 查询区间和 [l, r]
int query(int l, int r) {
    return prefix[r] - prefix[l-1];
}
```

## 二维前缀和

### 问题引入

给定一个 `n×m` 的矩阵，有 `q` 次查询，每次查询求子矩阵 `[x1,y1] 到 [x2,y2]`（左上角到右下角）的元素和。

### 核心思想

二维前缀和 `sum[i][j]` 表示以 `(1,1)` 为左上角，`(i,j)` 为右下角的矩阵内所有元素的和。

```
    j=1   j=2   j=3   j=4
i=1 [ a11  a12  a13  a14 ]
i=2 [ a21  a22  a23  a24 ]
i=3 [ a31  a32  a33  a34 ]
i=4 [ a41  a42  a43  a44 ]

sum[3][3] = 所有 a11 到 a33 的元素之和
```

### 公式推导

观察下图，构建 `sum[i][j]`：![image-20260325123215442](/home/michael/.config/Typora/typora-user-images/image-20260325123215442.png)

```
+-------------------+
|                   |  ← 这是 sum[i-1][j]
|                   |
+-------------------+
|            +------|----- sum[i][j-1]
|            |      |
|    a[i][j] |██████|
|            |██████|
+------------+------+
```

**构建公式**：
```
sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j]
```

解释：
- `sum[i-1][j]`：上方矩形
- `sum[i][j-1]`：左方矩形
- `sum[i-1][j-1]`：左上角重复计算的矩形（要减掉）
- `a[i][j]`：当前元素

### 查询子矩阵和

给定左上角 `(x1, y1)` 和右下角 `(x2, y2)`：

```
            x1-1
    +--------+---------------------
    |        |                     |
    |        |    要求子矩阵        |
 y1-1  ------+---------------------
    |   |    |█████████████████████|
    |   |    |█████████████████████|
    |   |    |█████████████████████|
    +---+----+---------------------
        |    (x1,y1)    (x2,y2)
```

**查询公式**：
```
子矩阵和 = sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]
```

### 直观理解

同样使用"容斥原理"——加两次减一次：
- 先加上大矩形 `sum[x2][y2]`
- 再减去上方多算的部分 `sum[x1-1][y2]`
- 再减去左方多算的部分 `sum[x2][y1-1]`
- 但左上角被减了两次，要加回来 `sum[x1-1][y1-1]`

### 代码实现

```cpp
// 构建二维前缀和（1-indexed）
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j];
    }
}

// 查询子矩阵和 [x1,y1] 到 [x2,y2]
int query(int x1, int y1, int x2, int y2) {
    return sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1];
}
```

## 前缀和在最大正方形问题中的应用

### 问题回顾

在 `n×m` 的 0/1 矩阵中，找出不包含 0 的最大正方形的边长。

### 为什么用前缀和？

对于每个可能的正方形，我们需要快速判断它是否全为 1。朴素的检查方法是遍历正方形内所有元素，时间复杂度 O(k²)。

使用二维前缀和后，**O(1)** 就能算出任意子矩阵的元素和！

### 核心思路

1. **预处理**：构建二维前缀和
2. **枚举**：遍历所有可能的正方形（左上角、右下角、边长）
3. **判断**：用前缀和公式计算当前正方形的元素和
4. **验证**：如果和等于边长²，说明全为 1

### 判断条件详解

对于边长为 `l`、右下角为 `(i, j)` 的正方形：

```
左下角: (i-l+1, j-l+1)
右下角: (i, j)
```

使用前缀和判断：
```cpp
int squareSum = sum[i][j] - sum[x1-1][j] - sum[i][y1-1] + sum[x1-1][y1-1];
if (squareSum == l * l) {
    // 全为 1
}
```

### 完整代码框架

```cpp
// 1. 读入并构建前缀和
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        cin >> num[i][j];
        sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + num[i][j];
    }
}

// 2. 枚举边长
int ans = 0;
for (int l = 1; l <= min(n, m); ++l) {
    // 3. 枚举所有可能的右下角
    for (int i = l; i <= n; ++i) {
        for (int j = l; j <= m; ++j) {
            int x1 = i - l + 1, y1 = j - l + 1;
            int squareSum = sum[i][j] - sum[x1-1][j] - sum[i][y1-1] + sum[x1-1][y1-1];
            if (squareSum == l * l) {
                ans = max(ans, l);
            }
        }
    }
}
```

### 时间复杂度分析

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| 构建前缀和 | 遍历矩阵一次 | O(n×m) |
| 枚举边长 | min(n,m) | O(min(n,m)) |
| 枚举位置 | 对每条边长，遍历 (n-l+1)×(m-l+1) 个位置 | O(n×m×min(n,m)) |
| **总计** | | **O(n×m×min(n,m))** |

## 常见题型总结

### 一维前缀和适用场景
- 区间求和查询
- 连续子数组问题
- 平均值问题

### 二维前缀和适用场景
- 矩阵区域求和
- 子矩阵问题
- 统计满足条件的子矩阵个数

### 关键技巧

1. **数组下标从 1 开始**：简化边界处理
2. **注意越界**：`sum[0][*]` 和 `sum[*][0]` 应初始化为 0
3. **使用容斥原理**：理解"加两次减一次"
4. **预处理优于查询**：先构建前缀和，再回答查询

### 模板记忆

```
一维前缀和:
    构建: prefix[i] = prefix[i-1] + arr[i]
    查询: prefix[r] - prefix[l-1]

二维前缀和:
    构建: sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j]
    查询: sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]
```
