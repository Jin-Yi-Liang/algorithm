# LC713 乘积小于K的子数组

## 核心思路

**滑动窗口**：维护一个乘积小于 k 的窗口

1. 右指针 r 扩展窗口，乘积 cur 不断乘以 nums[r]
2. 当 cur >= k 时，左指针 l 收缩窗口，同时 cur /= nums[l]
3. 每次窗口有效时，贡献 `r - l + 1` 个子数组（以 r 为右端点的所有合法子数组）

## 关键点

- `while(l <= r && cur >= k)` 中 `l <= r` 而非 `l < r`
  - 当窗口只剩一个 ≥k 的元素时，必须允许左指针越过头部使窗口为空
  - 否则会错误计数该单元素子数组
- k <= 1 时直接返回 0（任何非空子数组乘积都 ≥ 1 ≥ k）
- 贡献计算：`ans += (r - l + 1)` = 窗口长度 = 以 r 为右端点的合法子数组个数

## 时间复杂度

- 每个元素最多被左右指针各访问一次：O(n)
