# 序列（全局加数与最大子序列和）

## 题目描述

给定一个长度为 n 的序列，支持两种操作：
1. `1 k`：给序列中每个元素加上 k
2. `2`：查询当前序列的最大子序列和（子序列可以为空，和为 0）

## 核心洞察

最大子序列和 = 所有正数之和（若没有正数则为 0）。

- 全局加法只改变元素的实际值，不改变相对顺序，因此元素的"是否应当选取"仅取决于其实际值的正负
- 由于只关心正负，可以对原数组排序，用二分快速定位第一个实际值 ≥ 0 的元素位置
- 每次查询答案 = (后缀原始值之和) + (后缀元素个数) × delta

## 单调性

随着 delta 增加，二分阈值 `-delta` 单调递减（即第一个 ≥ 0 的位置不断左移）。

## 算法流程

```
初始数组: [-5, 12, -7, 2, 8]
排序后 num: [-7, -5, 2, 8, 12]    sum: [-7, -12, -10, -2, 10]

操作1: 2 (查询)    delta=0
  二分: 找 num[i]+0 >=0 → 第一个是 2 (位置3)
  ans = sum[5]-sum[2] + (5-3+1)*0 = 10 - (-12) + 0 = 22

操作2: 1 3        delta=3
  实际数组: [-4, -2, 5, 11, 15]

操作3: 2 (查询)    delta=3
  二分: 找 num[i]+3 >=0 → -5+3=-2 ✗ → -7+3=-4 ✗ → 2+3=5 ✓，位置3
  ans = (10 - (-12)) + 3*3 = 22 + 9 = 31

操作4: 1 4        delta=7
  实际数组: [0, 2, 9, 15, 19]

操作5: 2 (查询)    delta=7
  二分: 找 num[i]+7 >=0 → -7+7=0 ✓，位置1
  ans = (10 - 0) + 5*7 = 10 + 35 = 45
```

## 复杂度分析

| 维度 | 分析 | 结论 |
|------|------|------|
| 时间复杂度 | 排序 O(n log n)，每次查询 O(log n)，共 m 次操作 | O(n log n + m log n) |
| 空间复杂度 | 存储原数组、前缀和数组，大小 O(n) | O(n) |

## 关键易错点

```cpp
// 易错点1：delta 累加溢出
// k 和 delta 必须用 long long，因为最多 5e5 次累加 5e5，总和可达 2.5e11，超过 int 范围
ll delta = 0;    // 正确
int delta = 0;   // 错误，会溢出导致 WA

// 易错点2：二分未找到时的返回值
// 当所有元素实际值都 < 0 时，应返回 n+1，这样 sum[n]-sum[n] + 0*delta = 0
int ans = n + 1;   // 正确

// 按照题意，子序列可以为空，和为 0。但实际公式在 pos 正确时不会出现负数
```
