# 同色路径 - 题解笔记

## 核心思想：DFS/BFS 遍历树，递推统计

### 问题转化

统计所有满足条件的同色路径（祖先→后代，方向从祖先到后代）。

**关键观察**：每条路径一定有终点，可以遍历每个节点，统计以该节点为**终点**的合法路径数量，求和即为答案。

### 关键数组 `len[v]`

`len[v]` 表示从节点 `v` 开始向上（向根方向）**连续相同颜色的节点个数**（包括 `v` 自身）。

- 例如链 `a → b → c` 颜色相同：则 `len[c]=3, len[b]=2, len[a]=1`
- 以 `v` 为终点的合法路径数 = `len[v] - 1`（排除自身起点）

### 递推关系

在 BFS/DFS 遍历时，父节点为 `u`，子节点为 `v`：
- 若 `c[v] == c[u]`：可接在后面 → `len[v] = len[u] + 1`
- 否则：重新开始 → `len[v] = 1`

答案累加：`ans += len[v] - 1`

### 为什么用无向图存储？

题目输入只给出 `n-1` 条边，没有指定父→子的方向。存储为无向图（邻接表），从根节点 1 开始 BFS，通过 `visited` 数组避免走回头路。这是树问题的标准处理方式。

### 举例验证（样例1）

```
1(1)
 └2(1)
   ├3(2)
   └4(1)
     └5(2)
```

- 节点1: len=1 → 贡献 0
- 节点2: 父节点同色 → len=2 → 贡献 1（路径 1→2）
- 节点3: 父节点不同色 → len=1 → 贡献 0
- 节点4: 父节点同色 → len=3 → 贡献 2（路径 2→4、1→2→4）
- 节点5: 父节点不同色 → len=1 → 贡献 0

总贡献 = 3，正确。

### 常见错误

1. **根节点 len 未初始化**：BFS 前需设置 `len[1] = 1`
2. **只加单向边**：树是无向图，必须 `addEdge(u,v)` 和 `addEdge(v,u)` 都加
3. **未标记 visited**：避免子节点回指父节点

### 复杂度

- 时间：`O(n)` 遍历所有节点和边
- 空间：`O(n)` 存储邻接表和辅助数组
