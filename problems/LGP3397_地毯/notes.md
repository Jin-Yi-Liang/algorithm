# 洛谷 P3397 - 地毯

## 题目链接
https://www.luogu.com.cn/problem/P3397

## 思路
**二维差分** + **二维前缀和还原**

在 n×n 的棋盘上放 m 块地毯，每块地毯覆盖矩形区域 `[lx,ly] 到 [rx,ry]`（1-indexed），问每个格子被多少块地毯覆盖。

### 二维差分操作

对子矩阵 `[x1,y1,x2,y2]` 加上 v（这里 v=1）：
```cpp
++a[x1][y1];
--a[x2+1][y1];
--a[x1][y2+1];
++a[x2+1][y2+1];
```

### 二维前缀和还原
```cpp
for(int i=1;i<=n;++i)
    for(int j=1;j<=n;++j)
        sum[i][j] = sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1] + a[i][j];
```

## 复杂度
- 时间：O(n² + m)，n≤1000 完全够用
- 空间：O(n²)

## 关键点
- **差分数组 a[][] 先全部为 0**
- **还原时用 sum 数组**（不要直接修改 a，否则会影响差分）
- 下标从 1 开始，简化边界处理
