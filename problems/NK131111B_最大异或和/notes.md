# 最大异或和 - 题解笔记

## 核心思想：位运算 + 枚举

### 操作本质

题目中每次操作只能将 `x` 变成 `⌊x/2⌋`，即**二进制右移一位**（丢弃最低位）。

因此经过若干次操作后，`x` 最终可以变成 `x >> i`（`i ≥ 0`），同理 `y` 可以变成 `y >> j`（`j ≥ 0`）。

### 目标

选择非负整数 `i, j`，使得 `(x >> i) ⊕ (y >> j)` **最大**。

### 枚举方法

由于 `x, y ≤ 10^9 < 2^30`，所以 `i, j` 只需要枚举 `0` 到 `30` 即可。

- 右移超过 30 位后值为 0
- 但 `0 ^ 另一个数 = 另一个数本身`，所以实际上枚举到 30 已经覆盖所有可能

### 复杂度分析

- 每个测试数据中，`x, y` 最多 30 位
- 右移次数 `i, j` 各从 0 到 30，共 `31 × 31 = 961` 种组合
- 总测试数据 `T ≤ 2×10^4`，总操作次数约为 `2×10^4 × 961 ≈ 1.92×10^7`
- 每次操作只做整数右移和异或，常数极小，在 C++ 中约 0.2 秒即可完成

### 关键代码

```cpp
for(int i=0;i<32;++i){
    xx=x>>i;
    for(int j=0;j<32;++j){
        yy=y>>j;
        ans=max(ans,xx^yy);
    }
}
```

枚举所有 `(x>>i, y>>j)` 组合，取异或最大值。

### 为什么这样不会漏掉更优解？

因为任何操作序列最终等价于分别对 `x` 和 `y` 进行若干次右移，且右移次数**独立选择**。
枚举所有次数组合即可覆盖**所有可能的最终数对**，时间复杂度 `O(T·31²)` 可接受。
