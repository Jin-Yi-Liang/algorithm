# 前缀 XOR 求区间值

## 前缀 XOR 与前缀和的类比

### 前缀和怎么做的

```
原数组:    4  2  4  8
前缀和:  0  4  6  10  18

区间[2,4]的和 = prefix[4] - prefix[1] = 18 - 4 = 14  ✓
```

**关键操作是"减法"**，因为加法的逆运算是减法。

### 前缀 XOR 完全同理

XOR 的逆运算还是 XOR（因为 `a ^ a = 0`）

```
原数组:      4   2   4   8
前缀XOR:  0   4   6   2   10

区间[2,4]的XOR = prefix[4] ^ prefix[1] = 10 ^ 4 = 14  ✓
```

> **用减法还原加法 → 用 XOR 还原 XOR**

### 为什么 `prefix[r] ^ prefix[l-1]` 能得到区间值？

```
prefix[r]   = a[1] ^ a[2] ^ ... ^ a[l-1] ^ a[l] ^ ... ^ a[r]
prefix[l-1] = a[1] ^ a[2] ^ ... ^ a[l-1]

两者 XOR：
= (a[1]^...^a[l-1]) ^ (a[1]^...^a[l-1]) ^ a[l]^...^a[r]
=            0                              ^ a[l]^...^a[r]
= a[l] ^ a[l+1] ^ ... ^ a[r]   ✓
```

前面重叠的部分**自己异或自己消掉了**（`x ^ x = 0`）

## 二重循环的含义

```cpp
for(int i = 1; i <= n; ++i)       // i 枚举左端点
    for(int j = i; j <= n; ++j)    // j 枚举右端点
        ans = max(ans, num[j] ^ num[i-1]);
        //               ^^^^^^^^^^^
        //          = prefix[r] ^ prefix[l-1]
        //          = 区间[i, j] 的 XOR 值
```

本质上就是枚举所有可能的 `(l, r)` 组合，只不过通过前缀数组把区间 XOR 转化成了两个前缀值的 XOR。

## 复杂度

- 预处理：O(n) 建立前缀 XOR
- 枚举区间：O(n²) 枚举所有区间
- 总体：O(n²)，本题 n≤100 足够
