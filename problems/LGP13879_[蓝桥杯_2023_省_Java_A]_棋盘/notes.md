# LGP13879 [蓝桥杯 2023 省 Java A] 棋盘

## 核心思路

**二维差分数组**：将 m 次 O(n²) 的区间翻转优化为 O(m) 的差分更新

1. 对每次操作 (x1,y1,x2,y2)，在差分数组上做四点更新：
   - `w[x1][y1]++`, `w[x1][y2+1]--`, `w[x2+1][y1]--`, `w[x2+1][y2+1]++`
2. 对差分数组做二维前缀和，得到每个格子的翻转次数
3. 翻转次数 % 2 = 0 → 白色(0)，奇数次 → 黑色(1)

## 关键点

- 差分使得区间操作从 O(n²) 变为 O(1)
- 最终颜色只与翻转次数的奇偶性有关
- 时间复杂度 O(n² + m)，空间 O(n²)
