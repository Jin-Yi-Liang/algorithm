# 洛谷 P1387 - 最大正方形

## 题目链接
https://www.luogu.com.cn/problem/P1387

## 思路
**二维前缀和** + 枚举边长

核心思想：枚举所有可能的正方形，O(1) 验证每个正方形内是否全为 1。

### 二维前缀和
```cpp
S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + a[i][j]
```

### 验证正方形
给定边长 `l`，右下角 `(i, j)`，则左上角为 `(i-l+1, j-l+1)`。
```
面积 = S[i][j] - S[i][y-1] - S[x-1][j] + S[x-1][y-1]
```
如果面积 == `l*l`，说明整个正方形内全是 1。

### 时间复杂度
- 枚举边长 `l`（1 到 min(n,m)）
- 枚举右下角 `(i, j)`
- O(1) 验证

总体 O(min(n,m) × n × m × 1) ≈ O(n × m × min(n,m))，但 n,m ≤ 100 完全够用。

## 代码要点
```cpp
// 预处理前缀和（下标从1开始，避免边界处理）
for(int i=1;i<=n;++i)
    for(int j=1;j<=m;++j)
        sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + num[i][j];

// 枚举边长 l，然后枚举行列作为右下角
for(int l=1; l<=min(n,m); ++l)
    for(int i=l; i<=n; ++i)
        for(int j=l; j<=m; ++j)
            if (区域内全是1) ans = max(ans, l);
```

## 关键点
- **前缀和下标从 1 开始**：这样 `sum[i][j-1]`、`sum[i-1][j]` 不会出现负下标
- **面积验证**：前缀和的差分运算能 O(1) 得到任意子矩阵的元素之和
- **只求最大边长**：不需要记录具体位置，只需不断更新 ans
