# L1-006 连续因子

## 核心思路

**枚举起点 + 滑动窗口计算长度**

1. **枚举起点 i**（从 2 到 √n）：假设连续因子从 i 开始
2. **滑动扩展**：从 i 不断乘以 j，直到 n 不能整除 prod 为止
3. **更新答案**：每次扩展时，如果 `j-i+1 > len`，则更新 len 和 start

## 关键点

- 连续因子长度不会超过 √n（因为最小的因子是 2）
- 如果没有任何因子（len==0），说明 n 本身就是质数，输出 `1\nn`
- 外层循环到 √n 即可，因为连续因子若长度≥2，则最小的因子 ≤ √n

## 时间复杂度

- 外层：O(√n)
- 内层：O(√n)
- 最坏 O(n)，实际很快因为 √n ≤ 46340（n < 2^31）
