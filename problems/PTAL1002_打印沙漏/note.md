# PTAL1002 打印沙漏

## 题目描述

给定 N 个符号，打印出用掉尽可能多符号的沙漏形状。

**沙漏规则**：
- 每行奇数个符号
- 各行中心对齐
- 相邻行差 2 个符号
- 先递减到 1，再递增回去
- 首尾符号数相等

## 数学规律

假设半高为 `h`：
- h=1：1 个符号
- h=2：7 个符号（上层 3 + 中心 1 + 下层 3）
- h=3：17 个符号

**公式**：完整沙漏需要 `2h² - 1` 个符号

由 `2h² - 1 ≤ N` 得：`h = sqrt((N + 1) / 2)`

剩余：`remain = N - (2h² - 1)`

## 核心思想

**沙漏对称法则** — 上下两半场内部逻辑完全相同，区别只是层级 i 递减还是递增：

| 层级 i | 星号数 `2i-1` | 前导空格 `h-i` |
|--------|--------------|---------------|
| 3      | 5            | 0             |
| 2      | 3            | 1             |
| 1      | 1（中心）    | 2             |

上半场：`i` 从 `h` 递减到 `1`
下半场：`i` 从 `2` 递增到 `h`

## 代码

```cpp
int h = sqrt((n + 1) / 2);  // 求半高
int remain = n - (2 * h * h - 1);

// 上半场（含中心）
for (int i = h; i >= 1; --i) {
    for (int j = 0; j < h - i; ++j) cout << " ";
    for (int j = 0; j < 2 * i - 1; ++j) cout << ch;
    cout << endl;
}

// 下半场（不含中心）
for (int i = 2; i <= h; ++i) {
    for (int j = 0; j < h - i; ++j) cout << " ";
    for (int j = 0; j < 2 * i - 1; ++j) cout << ch;
    if (i != h) cout << endl;
}
cout << endl << remain;
```
