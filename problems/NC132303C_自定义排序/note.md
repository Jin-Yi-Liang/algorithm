# NC132303C 自定义排序

## 题目描述

给定 n 个小写字母字符串，按自定义规则排序：
1. 按字符 a~z 的出现次数比较，次数多的字符串"更小"（排前面）
2. 所有字符次数相同则按字典序比较

## 核心思想

**"奥运会奖牌榜"规则** — 字符 'a' 的出现次数是"金牌"，'b' 是"银牌"，以此类推。金牌多的排前面，金牌相同比银牌...

## 算法步骤

1. **统计频率**：对每个字符串统计 26 个字母的出现次数
2. **自定义比较器**：按频率从 a 到 z 依次比较，次数多的排前面
3. **字典序兜底**：频率完全相同则用 `std::string` 的 `<` 运算符比较字典序

## 代码要点

```cpp
struct Node {
    string str;
    int num[26] = {0};  // 固定大小数组，避免 vector 越界
};

bool cmp(Node& a, Node& b) {
    for (int i = 0; i < 26; ++i) {
        if (a.num[i] > b.num[i]) return true;   // a 次数多，a 更小
        else if (a.num[i] < b.num[i]) return false; // b 次数多，b 更小
    }
    return a.str < b.str;  // 字典序兜底（std::string 自带处理前缀）
}
```

## 关键点

- **严格弱序**：`cmp` 返回 `false` 表示两者相等或 a 应在 b 后面。不能 return `true` 表示相等
- **固定数组**：`int num[26] = {0}` 初始化为 0，避免 vector 下标越界
- **绑定结构体**：字符串和频率数组绑定在同一个 struct，排序时不分离
