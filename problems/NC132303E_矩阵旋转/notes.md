# 矩阵旋转（牛客 132303E）

## 核心思路：时光倒流法（离线单点追踪）

**放弃全局模拟**：q ≤ 10^5 的矩阵旋转操作不可能逐个模拟，使用**逆序遍历操作记录**，让查询点"坐时光机"倒推原始坐标。

## 关键技巧：局部降维与升维

1. **降维**：`rx = dx - cur.x`, `ry = dy - cur.y`（以子矩阵左上角为原点）
2. **旋转**（相对坐标）：
   - 撤销顺时针（操作1）：`new_rx = len - 1 - ry`, `new_ry = rx`
   - 撤销逆时针（操作2）：`new_rx = ry`, `new_ry = len - 1 - rx`
3. **升维**：`dx = new_rx + cur.x`, `dy = new_ry + cur.y`

## 避坑

1. **Off-by-one**：边界是 `x + len - 1`，不是 `x + len`
2. **相对视野**：公式里的 `len` 是**子矩阵边长**，不是大矩阵 `n`
3. **整数溢出**：`n * (dx - 1)` 需用 `long long`，或加 `1LL *` 强制转换
